# Personal Portfolio

A responsive portfolio website built with React, Vite, TypeScript, and Tailwind CSS.

## Features

- Hero section with animated intro
- Skills, projects, experience, education, and certification sections
- Interactive certificate modal supporting PDFs and images
- Scroll progress indicator
- Tailwind CSS styling with custom components

## Prerequisites

- Node.js 18.x
- npm 10.x

## Run locally

```bash
npm install
npm run dev
```

Open the app in your browser at:

```text
http://localhost:3000/
```

## Build for production

```bash
npm run build
```

## Notes

- `npm start` is not configured for this project.
- PDF certificates are stored in `public/certs` and open in the browser modal or a new tab.
